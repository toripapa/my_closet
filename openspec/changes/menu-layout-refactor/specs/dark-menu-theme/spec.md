## ADDED Requirements

### Requirement: TopMenuBar와 SideMenuPanel은 다크 배경을 사용한다
TopMenuBar(AppBar)와 SideMenuPanel(좌측 서브메뉴 컨테이너)의 배경색은 다크 계열(#1A1A2E)이어야 하며, 텍스트 및 아이콘은 밝은 색상(#E0E0E0)으로 표시하여 메인 콘텐츠 영역(흰색 배경)과 시각적으로 명확히 구분되어야 한다.

#### Scenario: 메인 레이아웃 진입 시 다크 배경 메뉴바가 표시된다
- **WHEN** 사용자가 로그인하여 메인 레이아웃에 진입한다
- **THEN** AppBar 배경색이 다크 색상(#1A1A2E)으로 표시되고, 텍스트와 아이콘은 밝은 색(#E0E0E0)으로 표시된다

#### Scenario: 서브메뉴 패널도 다크 배경으로 표시된다
- **WHEN** 서브메뉴가 있는 1단계 메뉴(예: 내 옷장)를 클릭한다
- **THEN** 좌측에 표시되는 SideMenuPanel의 배경색이 다크 색상(#1A1A2E)이고, 서브메뉴 텍스트는 밝은 색으로 표시된다

### Requirement: 선택된 메뉴 항목은 다크 테마 내에서 시각적으로 강조된다
선택된 상단 메뉴 버튼과 서브메뉴 항목은 다크 배경 위에서도 구분 가능한 강조 배경(#2D2D44)과 흰색 텍스트로 표시되어야 한다.

#### Scenario: 선택된 상단 메뉴 버튼에 강조 배경이 적용된다
- **WHEN** 사용자가 특정 1단계 메뉴를 선택한다
- **THEN** 해당 버튼의 배경이 강조 색상(#2D2D44)으로 변경되고, 텍스트는 흰색(#FFFFFF)으로 표시된다
