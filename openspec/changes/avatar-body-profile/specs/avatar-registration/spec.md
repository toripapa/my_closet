## MODIFIED Requirements

### Requirement: 아바타 등록/수정 버튼 상태 분기
`/home/avatar` 페이지는 아바타 등록 여부에 따라 버튼을 다르게 표시해야 한다. 아바타가 등록되지 않은 경우 "아바타 등록" 버튼을 표시하고, 등록 완료된 경우 "아바타 수정"과 "아바타 삭제" 두 버튼을 모두 표시해야 한다.

#### Scenario: 아바타 미등록 상태에서 페이지 진입
- **WHEN** 사용자가 아바타를 등록한 적 없는 상태로 `/home/avatar` 페이지에 진입하면
- **THEN** "아바타 등록" 버튼이 표시되어야 한다
- **THEN** "아바타 수정" 버튼과 "아바타 삭제" 버튼은 표시되지 않아야 한다

#### Scenario: 아바타 등록 완료 후 페이지 표시
- **WHEN** 사용자가 아바타를 성공적으로 등록한 후 `/home/avatar` 페이지를 표시하면
- **THEN** 생성된 아바타 이미지가 플레이스홀더 영역에 표시되어야 한다
- **THEN** "아바타 수정" 버튼이 표시되어야 한다
- **THEN** "아바타 삭제" 버튼이 표시되어야 한다
- **THEN** 저장된 신체 정보(키, 몸무게, 상의 사이즈, 하의 사이즈, 신발 사이즈)가 모두 표시되어야 한다

### Requirement: 아바타 등록 버튼 클릭 시 가이드 페이지 이동
"아바타 등록" 버튼을 클릭하면 아바타 등록 가이드 페이지로 이동해야 한다.

#### Scenario: 아바타 등록 버튼 클릭
- **WHEN** 사용자가 "아바타 등록" 버튼을 클릭하면
- **THEN** 시스템은 `/home/avatar/guide` 페이지로 이동해야 한다
