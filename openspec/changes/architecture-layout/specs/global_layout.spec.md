# Global Application Layout

## Overview

인증된 사용자 이후 메인 앱의 기본 레이아웃 구조로, 상단 메뉴/좌측 서브메뉴/본문 영역의 3단 구조를 제공합니다.

## Requirements

- **상단 메뉴 영역(1)**: 7개 주 메뉴 항목 (홈, 내 아바타, 내 옷장, 나의 집, 날씨, 커뮤니티, 설정)
- **좌측 메뉴 영역(2)**: 상단 메뉴 별 서브메뉴 표시 (계층적 메뉴)
- **본문 영역(3)**: 선택된 메뉴에 해당하는 콘텐츠 렌더링
- **반응형**: 데스크톱/태블릿 환경 지원
- **일관된 스타일**: 미니멀/모노톤 디자인 적용

## Layout Structure

```
┌─────────────────────────────────────────┐
│         Top Menu Bar (1)                  │
│  [Home] [Avatar] [Wardrobe] [House] ...  │
├──────────┬──────────────────────────────┤
│ Left     │                               │
│ Menu (2) │   Content Area (3)           │
│          │   (페이지별 콘텐츠)           │
│  - Item  │                               │
│  - Item  │                               │
│          │                               │
└──────────┴──────────────────────────────┘
```

## Inputs

- 사용자 메뉴 클릭

## Outputs

- Scaffold + AppBar + Row 레이아웃 렌더링
- 선택된 메뉴 강조 표시

## Acceptance Criteria

- [ ] 화면 로드 시 3단 레이아웃 표시
- [ ] 모든 메뉴 항목이 클릭 가능
- [ ] 모노톤 색상 일관성 유지
- [ ] 터치/호버 피드백 작동

## Notes

- 좌측 메뉴 너비: 250px (고정)
- 모바일 환경에서는 드로어로 변경 예정 (현재 스코프 외)
