## ADDED Requirements

### Requirement: 아바타 등록 가이드 페이지 표시
`/home/avatar/guide` 페이지는 사용자가 올바른 아바타 생성을 위해 카메라 촬영 방법을 안내하는 가이드 내용을 표시해야 한다.

#### Scenario: 가이드 페이지 진입 시 안내 문구 표시
- **WHEN** 사용자가 `/home/avatar/guide` 페이지에 진입하면
- **THEN** "본인 전체 모습을 카메라로 촬영 해주세요" 문구가 표시되어야 한다
- **THEN** "정면에서 정확하게 찍어야 아바타 생성이 잘 됩니다" 문구가 표시되어야 한다
- **THEN** "확인" 버튼이 표시되어야 한다

### Requirement: 가이드 확인 버튼 클릭 시 카메라 실행
가이드 페이지에서 "확인" 버튼을 클릭하면 카메라 앱이 실행되어야 한다.

#### Scenario: 확인 버튼 클릭 시 카메라 실행
- **WHEN** 사용자가 가이드 페이지의 "확인" 버튼을 클릭하면
- **THEN** 시스템은 카메라 촬영 기능을 실행해야 한다

#### Scenario: 카메라 권한이 없는 경우
- **WHEN** 카메라 권한이 거부된 상태에서 "확인" 버튼을 클릭하면
- **THEN** 권한 안내 다이얼로그를 표시하고 설정 앱으로 이동하는 버튼을 제공해야 한다
